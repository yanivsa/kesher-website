# בקלוג יישום ארכיטקטורת PRs (Implementation Backlog & PR Sequence)

ארכיטקטורת היישום בנויה מסדרה של **Pull Requests קטנים, ממוקדים ובטוחים**, המפרידים באופן חד ומוחלט בין תשתית טכנית, פיילוט מבוקר, וגלגול רוחבי עתידי.

```
+---------------------------------------------------------------------------------------+
|                                רצף שלבי היישום (PR Architecture)                      |
+---------------------------------------------------------------------------------------+
| [PR 1: Technical Foundation]                                                          |
| תשתית סכמה קנונית, מודל תאריכים truthful, תמיכה ברכיבי תוכן, ולידציה ב-CI, טסטים       |
+---------------------------------------------------------------------------------------+
                                            |
                                            v
+---------------------------------------------------------------------------------------+
| [PR 2: Controlled Pilot 5 URLs]                                                       |
| שדרוג 5 עמודי הפיילוט בלבד, רשת קישורים פנימית לאשכולות, הוספת ראיות ללא המצאת מידע   |
+---------------------------------------------------------------------------------------+
                                            |
                                            v
+---------------------------------------------------------------------------------------+
| [PR 3: Bulk Rollout & Automation - עתידי ומדורג]                                      |
| האצלה הדרגתית של 15 המאמרים הבאים ל-Jules לפי תבנית מאומתת ובדיקות CI דטרמיניסטיות   |
+---------------------------------------------------------------------------------------+
```

## 1. מפרט PR 1: תשתית טכנית (Technical Foundation)

- **כותרת PR:** `feat(aeo): implement canonical entity, truthful date model, and content schema foundation`
- **מטרה:** יצירת תשתית הקוד, הסכמה, והוולידציה הנדרשת ל-AEO ללא שינוי בתוכן המאמרים.
- **תלויות:** אין. מתבסס ישירות על `origin/main`.
- **קבצים מושפעים צפויים:**
  - `.agents/skills/aeo-kesher/SKILL.md` [NEW] — מיומנות פרויקט קבועה לחוקי AEO.
  - `src/pages/About/AboutPage.tsx` [MODIFY] — חיבור ה-Person ב-ProfilePage ל-`#shira`.
  - `src/pages/Blog/BlogPost.tsx` [MODIFY] — סכמת מאמר קנונית, שיוך מחבר ל-`#shira`, תמיכה ב-`dateModified` ורכיבי תצוגה אופציונליים (`directAnswer`, `evidence`, `expertInsight`).
  - `src/pages/Blog/BlogPost.module.css` [MODIFY] — עיצוב נקי ונגיש לרכיבי AEO.
  - `scripts/generate-sitemap.cjs` [MODIFY] — תמיכה ב-`lastmod` מהימן מתוך `updatedAt`.
  - `scripts/validate-content.cjs` [MODIFY] — הוספת בדיקות AEO (תאריכים, סכמה, איסור תביעות מומצאות).
  - `tests/aeo-foundation.test.ts` [NEW] — בדיקות יחידה מקיפות לתשתית.
- **בדיקות נדרשות:** `npm run check` מלא.
- **רמת סיכון:** נמוכה. כל השדות אופציונליים, תאימות מלאה אחורה ל-74 המאמרים הקיימים.
- **מודל מומלץ לביצוע:** Antigravity / Gemini 3.8 Flash (High/Medium).

## 2. מפרט PR 2: פיילוט מבוקר על 5 עמודים (Controlled Pilot)

- **כותרת PR:** `feat(aeo): enhance pilot 5 URLs with direct answers, evidence, and cluster links`
- **מטרה:** יישום השיפורים בחמשת עמודי הפיילוט שנבחרו בלבד לצורך אימות המודל בשטח.
- **תלויות:** תלוי במיזוג או התבססות על PR 1.
- **קבצים מושפעים צפויים:**
  - `src/pages/Services/Gifted/GiftedParentingPage.tsx` [MODIFY] — הפיכה ל-Hub, הוספת BLUF, FAQ וקישורי אשכול.
  - `src/pages/Landing/CouplesCounselingAshdod/CouplesCounselingAshdodPage.tsx` [MODIFY] — נרמול סכמת שירות מקומי וסנכרון ישויות.
  - `src/data/posts.json` [MODIFY] — עדכון ממוקד של 3 מאמרי הפיילוט (`gifted-adhd-...`, `newlywed-first-year-...`, `returning-to-israel-...`).
  - `docs/aeo/experiments.csv` [NEW] — מעקב מדדי בסיס והיפותזות.
- **בדיקות נדרשות:** `npm run check`, בדיקות Playwright E2E, אימות Playwright Prerender.
- **רמת סיכון:** נמוכה-בינונית (עמודי שירות פעילים — מחייב בדיקת אי-פגיעה ב-CRO ובנראות מובייל).
- **מודל מומלץ לביצוע:** Antigravity.

## 3. מפרט PR 3: אוטומציה והרחבה מדורגת (Future Jules Rollout)

- **כותרת PR:** `feat(aeo): batch retrofit 15 priority articles with subcategory and contextual links`
- **מטרה:** הרחבת התבנית המאומתת ל-15 המאמרים הבאים בבקלוג (דירוג 6–20).
- **תלויות:** הצלחת פיילוט PR 2 ואישור אנושי.
- **קבצים מושפעים:** `src/data/posts.json`.
- **חלוקת אחריות:**
  - **Jules:** משימות מוגדרות ודטרמיניסטיות בלבד — יישור שדה `subcategory`, הוספת שורות מחבר וקישורים פנימיים מוגדרים מראש.
  - **אנושי (שירה):** מענה לשאלות מומחה עבור מאמרים המסומנים ב-`needsExpertInput: true`.
  - **CI:** אכיפת אי-חריגה ממדיניות תוכן, בדיקות SHA-256 ומניעת המצאת עובדות.
