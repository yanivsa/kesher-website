# תוכנית פיילוט 5 עמודים מבוקרים (Pilot 5 URLs)

חמשת העמודים נבחרו כדי לבחון **5 היפותזות שונות** המשלימות זו את זו, במקום לבצע 5 עותקים של אותו שינוי:

```
+---------------------------------------------------------------------------------------------------+
|                                 תוכנית הפיילוט המבוקר (Pilot 5)                                   |
+---------------------------------------------------------------------------------------------------+
| 1. עמוד עוגן שירותי (Hub):  /services/gifted-parenting       -> היפותזת Hub & Spoke סמכותי          |
| 2. עמוד נחיתה מקומי:        /couples-counseling-ashdod      -> היפותזת יישור ישות מקומית וסכמה     |
| 3. מאמר עומק מבוסס ראיות:   /blog/gifted-adhd-...           -> היפותזת directAnswer + שכבת ראיות   |
| 4. מאמר החלטה והשוואה:      /blog/newlywed-first-year-...   -> היפותזת טבלת החלטה ומבנה השוואתי     |
| 5. מאמר מעבר חיים ו-BLUF:   /blog/returning-to-israel-...   -> היפותזת פסקאות עצמאיות לאחזור AI     |
+---------------------------------------------------------------------------------------------------+
```

## 1. פירוט חמשת עמודי הפיילוט

### עמוד פיילוט 1: `/services/gifted-parenting` (עמוד עוגן — הנחיית הורים למחוננים)
- **מבצר נושאי:** מבצר ב' — מחוננות והפרעת קשב בהורות.
- **היפותזה מרכזית:** הפיכת עמוד שירות סטנדרטי ל-Pillar Hub מבוסס AEO (הכולל תשובת פתיחה ישירה, שאלות-תשובות מובנות ורשת קישורים הדדית למאמרי העומק באשכול) תגביר את אחזור העמוד כמענה ראשי לשאילתות הורים ותחזק את הסמכות הנושאית של האתר.
- **שינויים מתוכננים:**
  1. הוספת פסקת מענה תמציתית (BLUF) המגדירה מהי הנחיית הורים למחוננים ומתי כדאי לפנות.
  2. הטמעת בלוק שאלות ותשובות ייעודי וסכמת `FAQPage` ספציפית לנושא מחוננות.
  3. הוספת סקשן מובנה "מאמרי עומק וכלים מעשיים" המקשר ישירות ל-6 מאמרי האשכול.
  4. קישור מפורש לישות שירה סהרוני (`#shira`) כמנחה המקצועית של השירות.
- **מדדי מעקב:** הופעה בחיפושי AI סביב "הנחיית הורים למחוננים", קליקים ממאמרים לעמוד השירות, שיעור המרה לקביעת פגישה/וואטסאפ.
- **צורך בקלט מומחה (שירה):** כן — הגדרת תובנה קלינית ייחודית: "מה השגיאה הנפוצה ביותר שהורים עושים כשהילד מאובחן כמחונן?".

### עמוד פיילוט 2: `/couples-counseling-ashdod` (עמוד מסחרי-מקומי — ייעוץ זוגי באשדוד)
- **מבצר נושאי:** שכבה מקומית-מסחרית (אשדוד).
- **היפותזה מרכזית:** תיקון סכמת המידע המובנה מכפילות של שתי ישויות עסק מתחרות לישות שירות מקומי מוגדרת המקושרת לעסק הקנוני ולשירה סהרוני תשפר את הדיוק באחזור AI מקומי ללא פגיעה בשיעורי ההמרה הקיימים (CRO).
- **שינויים מתוכננים:**
  1. נרמול ה-JSON-LD: מעבר מסכמת `LocalBusiness` כפולה לעוגן `Service` מקומי עם `provider: {"@id": ".../#business"}` ואישור תחומי שירות באשדוד.
  2. וידוא עקביות של שם היועצת, תפקידה, פרטי ההתקשרות ואפשרויות הגישה (קליניקה באשדוד / אונליין).
  3. חיזוק הקישוריות הפנימית מדף הבית ומעמודי המאמרים העוסקים במשבר זוגי.
- **מדדי מעקב:** שמירה על יציבות המרות בוואטסאפ/קביעת תור, שיפור אזכור שם העסק בתשובות מקומיות ב-ChatGPT/Google AI.
- **צורך בקלט מומחה:** לא נדרש.

### עמוד פיילוט 3: `/blog/gifted-adhd-executive-functions-struggle` (מאמר עומק — מחוננות ו-ADHD)
- **מבצר נושאי:** מבצר ב' — מחוננות והפרעת קשב בהורות.
- **היפותזה מרכזית:** הוספת תשובה ממוקדת (`directAnswer`) בראש המאמר ושכבת אסמכתאות מחקריות אמינות (Evidence Layer — מחקרים על התפתחות אסינכרונית ותפקודים ניהוליים) תהפוך את המאמר למקור ציטוט מועדף במנועי בינה מלאכותית מבוססי RAG.
- **שינויים מתוכננים:**
  1. הוספת אלמנט `directAnswer` תמציתי ומדויק בפתיחה (תשובה לשאלה: "למה ילד מחונן שוכח ציוד ומתקשה להתארגן?").
  2. הוספת רכיב `evidence` עם 2–3 מקורות מחקריים רשמיים (למשל: מחקרי דברובסקי / התפתחות אסינכרונית ופרסומי מכון סאלד/משרד החינוך).
  3. הוספת שורת מחבר (Byline) רשמית המקשרת לדף אודות שירה (`/about`).
  4. קישור הדדי לעמוד העוגן `/services/gifted-parenting`.
- **מדדי מעקב:** ציטוט המאמר ב-Perplexity וב-ChatGPT Search לשאילתות "מחוננות והפרעת קשב בבית ספר", זמן שהייה במאמר.
- **צורך בקלט מומחה:** לא נדרש — קיים ביסוס מחקרי וקליני מוסכם.

### עמוד פיילוט 4: `/blog/newlywed-first-year-conflicts` (מאמר החלטה והשוואה — השנה הראשונה)
- **מבצר נושאי:** מבצר ד' — הכנה לנישואים והשנה הראשונה.
- **היפותזה מרכזית:** הוספת טבלת השוואה מובנית ("דפוס תגובה מעכב מול דרך תגובה בונה בריב בשנה הראשונה") תגדיל דרמטית את סיכויי חילוץ המידע על ידי AI Overviews עבור שאילתות השוואתיות ותספק ערך החלטה מיידי למשתמש.
- **שינויים מתוכננים:**
  1. הטמעת טבלת החלטה / השוואה סמנטית ונגישה (`<table>` תקנית).
  2. הוספת פסקה פותחת ממוקדת (BLUF) לשאילתת "על מה זוגות רבים הכי הרבה בשנה הראשונה?".
  3. חיזוק שורת המחבר ועדכון נתוני ה-JSON-LD.
  4. קישור פנימי לעמוד השירות `/services/premarital-first-year`.
- **מדדי מעקב:** שליפת הטבלה או סעיפיה בתשובות מנועי חיפוש, ירידה בשיעור נטישה.
- **צורך בקלט מומחה:** לא נדרש — המאמר הקיים מכיל דוגמאות מפורטות.

### עמוד פיילוט 5: `/blog/returning-to-israel-after-relocation-relationship` (מאמר מעבר חיים — חזרה מרילוקיישן)
- **מבצר נושאי:** מבצר ג' — עלייה, רילוקיישן וחזרה לישראל.
- **היפותזה מרכזית:** ארגון מחדש של מאמר נרטיבי ארוך לחטיבות תוכן עצמאיות (Independently Understandable Passages) עם מענה BLUF וסעיפי פעולה מוגדרים יאפשר למנועי AI לשלוף פסקאות רלוונטיות לתתי-שאילתות שונות ("הלם חזרה", "חלוקת תפקידים", "פערי ציפיות").
- **שינויים מתוכננים:**
  1. שילוב פסקת תשובה ישירה (BLUF) בתחילת המאמר.
  2. דיוק כותרות ה-`<h3>` לניסוחים שיחתיים התואמים שאילתות משתמשים.
  3. הוספת רכיב מקורות / ראיות מקצועיות על תופעת ה-Reverse Culture Shock.
  4. קישור פנימי לעמוד העוגן `/services/couples-aliyah-relocation`.
- **מדדי מעקב:** חשיפות אורגניות ואחזור תשובות עבור שאילתות של ישראלים חוזרים, מעבר לעמוד שירות ייעוץ רילוקיישן.
- **צורך בקלט מומחה:** לא נדרש.
